# Xe-Mod 0.1.0-alpha.1

First downloadable prototype for **Minecraft Java 26.3**, **Fabric Loader
0.19.5 or newer**, **Fabric API 0.162.0+26.3**, and **Java 25**.

Download `xe-mod-0.1.0-alpha.1.jar` for playing. The `-sources.jar` is for
developers and should not go in the mods folder.

## Included

- Exact, frame-scoped visibility-result memoization with camera/frustum
  invalidation and a cross-thread fallback. This experiment is off by default;
  enable it with `/xe memo true`.
- Frame-time recording, average FPS, p99 frame time, and 1% low FPS exports.
- `/xe status` and `/xe diagnose` for feature state, startup-hook receipts,
  loaded versions, and the first captured feature failure.
- `-Dxe.safeMode=true` skips the optimization hook while keeping diagnostics
  and frame recording available.

No render-distance, resolution, lighting, particle, entity, texture, or gameplay
settings are reduced. No shader/resource packs or other performance mods are
included.

## Install

1. Create/select a Minecraft **26.3 Fabric** profile with Java 25.
2. Put the runtime Xe-Mod JAR and the matching Fabric API JAR in that profile's
   `mods` folder.
3. Launch and enter a world. Run `/xe status` to confirm Xe-Mod is loaded.
4. To try the cache, run `/xe memo true`. Run `/xe memo false` to turn it off.

For a useful comparison, use the same world, route, native resolution, render
distance, and FPS cap. Use `/xe label <scene>` then `/xe benchmark start`, run the
route, and use `/xe benchmark stop`. Files stay in the game's `xe-benchmarks`
folder. `/xe diagnose` writes to `xe-diagnostics`.

## Evidence and limits

This exact source commit was built with Java 25. Before release preparation,
the automated Minecraft client launched successfully in normal and safe mode.
The normal-mode check exercised 12,000 generated/expanded AABB comparisons,
repeated queries, camera/frustum changes, and running frame capture. Both hook
receipts were recorded and the normal-mode check recorded 12,024 cache hits.

Build and checks: https://github.com/KyzerGoated/Xe-Mod/actions/runs/38528794581

These checks are not an FPS benchmark, a full-world visual comparison, or a
compatibility guarantee for every modpack. **No FPS increase is measured or
promised.** This is a prerelease, not a claim of bug-free stability. No additional
tests were started during release preparation; the existing built artifact is
being published unchanged. SHA-256 checksums are included.

If an optimization hook prevents startup, add `-Dxe.safeMode=true` to JVM
arguments and restart. Save `latest.log` and, when the game opens, `/xe diagnose`.
Runtime cache errors disable the experiment for that session and retain their
stage and stack trace. Startup errors identify the involved mixin in the log.

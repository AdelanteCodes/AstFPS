# Allocation-free native texture reference lookup

Native Minecraft26.3 TextureSlots.getMaterial calls isTextureReference and then allocates String.substring(1) for a reference such as `#all`, before querying its private map. The native Resolver constructs Object2ObjectArrayMap and transfers it directly into TextureSlots; no native map getter/mutator exposes it afterward. This is model/resource-loading work, not a claimed stationary-frame optimization.

The new typed overwrite preserves the isTextureReference invocation, including bundled ModernFix's null/empty guard, and leaves ordinary names unchanged. On an exact native fastutil8.5.18 array map with null default return value, the helper reads key/value/size through lazily resolved read-only VarHandles and compares the original string suffix directly. It scans backward, matching native lookup order. No suffix String or backing array is created on this path. No per-call callback/Operation argument arrays, global lookup cache, GPU/image close, or resource retention is added.

Custom maps, raw non-String keys, custom default return values, missing private field access or inconsistent array bounds use the original substring plus map.get operation. Null/empty reference inputs also delegate to preserve exception behavior if another mod changes validation. VarHandles link only on an actual eligible lookup, avoiding a fastutil class-transformation or plugin-time reflective lookup.

Static evidence: `work/texture-slots-native-javap.txt` shows original lookup/private map; `work/texture-slots-resolver-native-javap.txt` shows native construction and map transfer; `work/texture-slots-arraymap-javap.txt` lines261 onward shows reverse lookup with stored-key Objects.equals. A generic CharSequence lookup probe would not work, because native String.equals(probe) returns false. No Fabric/third-party rendering or lighting algorithm is copied.

Pinned FerriteCore9 reconstruction has no texture slot lookup hook. Bundled ModernFix only modifies isTextureReference for this class; that invocation remains intact. Other mods changing native getMaterial/array-map lookup behavior remain an opt-in compatibility boundary. Private library field layout is a pinned contract and missing fields fall back, rather than failing resource loading.

Startup flag: `-Dastfps.enableTextureSlotSuffixLookup=true`, safe mode off. Parent owns registration and build. No Minecraft, runtime/unit tests, benchmark or measured allocation/FPS result. The code removes explicit temporary allocations on the eligible path; JIT code generation and overall loading-time benefit remain unmeasured.
